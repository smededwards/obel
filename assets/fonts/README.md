# Noto fonts

These self-hosted WOFF2 files contain Latin subsets of Noto Sans, Noto Serif and Noto Sans Mono. They were downloaded from Google's font service on 25 October 2026, so visitors' browsers do not request fonts from Google. The fonts use the SIL Open Font License; see OFL.txt.

Source families: https://github.com/google/fonts/tree/main/ofl/notosans, https://github.com/google/fonts/tree/main/ofl/notoserif and https://github.com/google/fonts/tree/main/ofl/notosansmono.
