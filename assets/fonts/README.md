# Noto fonts

Self-hosted Latin WOFF2 subsets of Noto Sans, Noto Serif and Noto Sans Mono, obtained from Google's font service on 25 October 2026. No font requests are made to Google at runtime. See OFL.txt for the SIL Open Font License.

Source families: https://github.com/google/fonts/tree/main/ofl/notosans, https://github.com/google/fonts/tree/main/ofl/notoserif and https://github.com/google/fonts/tree/main/ofl/notosansmono.
